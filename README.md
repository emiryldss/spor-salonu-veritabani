# Gym Management Database System

This project is a relational database system designed for managing a gym environment using MySQL. The main goal of the project is to organize and manage gym-related data efficiently by applying fundamental database design principles.

The system includes multiple interconnected tables such as members, trainers, workouts, exercises, equipment, and payments. Each table is structured using primary keys and foreign keys to ensure data integrity and maintain relationships between entities.

Through this project, core database concepts such as normalization, relational modeling, and structured query design are implemented. The database allows tracking of member information, trainer assignments, workout programs, and other gym operations in a structured and scalable way.

Additionally, the project demonstrates the use of SQL queries for data insertion, retrieval, updating, and management. It provides a solid foundation for real-world applications such as gym automation systems or fitness management software.

This project was developed as part of a university database course to improve practical skills in SQL and database design.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Key Features
- Relational database design
- Use of primary and foreign keys
- Structured and normalized tables
- Basic CRUD operations (Create, Read, Update, Delete)
- Real-world gym management scenario
